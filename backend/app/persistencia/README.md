# Persistencia del proyecto

Este directorio contiene la capa de persistencia del **Sistema de Gestión de Mantenimiento**.

Su objetivo es gestionar la conexión con la base de datos PostgreSQL mediante SQLAlchemy, definir los modelos ORM y realizar las operaciones de acceso y almacenamiento de datos a través de los repositorios, manteniendo la independencia respecto a la lógica de negocio.
